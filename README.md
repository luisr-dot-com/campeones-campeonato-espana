# Campeones — Web v1.51

La última web V29 pasa a denominarse v1.5. Esta actualización es v1.51.

Nombres de equipos verificados contra las 40 asociaciones facilitadas el 08/10/2026. Se conservan los alias de los usuarios de BGA y la lógica de resultados, ELO y persistencia.

## Instalación

Sustituir index.html, app.js y styles.css por los archivos de este paquete y mantener assets/. Los enlaces de recursos usan v=1.51 para cargar la versión actualizada.

Esta entrega contiene únicamente la web. Mantener el Worker de producción vigente (V17); no requiere cambios para los nombres de equipos. Se conserva la clave de almacenamiento local existente para reutilizar los datos guardados.
